# MathSeriesCalculator

**MathSeriesCalculator** is a C++ console application that demonstrates mathematical computations using loops, powers, and arithmetic expressions. It includes multiple functions to calculate different series and expressions, useful for learning C++ loops, functions, and the `cmath` library.

## Features

- **q4(): Power Series Sum**  
  Calculates the sum of the series \(1^1 + 2^2 + 3^3 + ... + n^n\) for a given `n`.

- **q5(): Reverse Power Series**  
  Calculates the series sum \(\sum_{i=10}^{6} i^{i-1}\) and prints intermediate results.

- **q7(): Arithmetic Expression Evaluation**  
  Evaluates the expression `700*10 + 20%5 * 5 * 1000` and prints the result.

- **q6(): Placeholder Function**  
  Currently empty, reserved for future functionality.

## Prerequisites

- C++ compiler (e.g., GCC, MinGW, or Visual Studio)
- Basic knowledge of loops and functions in C++
